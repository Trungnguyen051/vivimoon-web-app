# The client never computes money

Every price a shopper sees — line prices, subtotal, vouchers, shipping — comes from `POST /api/cart/price`; the earlier client-side `cartSubtotal` helper was deleted, and the only remaining line-level multiplication in the codebase is a sanctioned GA4 analytics snapshot, not a price shown to anyone. This was chosen so a pricing-rule or voucher-eligibility change never requires a frontend release, and so guest and member pricing paths can never silently diverge. The cart page therefore has no server-fetched price either (the cart lives in `localStorage`, unreadable until client-side rehydration — see cart-store rehydration in ADR-0008); all pricing is a client-side call through `lib/api/client.ts` after rehydration, rendering a pending state until the first price resolves.
